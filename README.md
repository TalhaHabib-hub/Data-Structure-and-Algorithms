# Data Structures and Algorithms in C++

My practice code and solutions for Data Structures and Algorithms (DSA), written in C++ while I learn problem solving.

## About

This repository is where I keep everything I learn about DSA. Each topic has its own folder with clean, commented C++ code so I can revise it later and others can learn from it too.

## Topics Covered

- **Basics:** time and space complexity, recursion
- **Arrays and Strings**
- **Linked Lists:** singly, doubly, circular
- **Stacks and Queues**
- **Trees:** binary tree, binary search tree, traversals
- **Heaps and Priority Queues**
- **Hashing**
- **Graphs:** BFS, DFS, shortest path
- **Sorting:** bubble, selection, insertion, merge, quick
- **Searching:** linear search, binary search
- **Dynamic Programming** (basics)

> Add or remove topics to match what you have actually completed.

## How to Run

Make sure you have a C++ compiler such as `g++` installed.

```bash
# Clone the repository
git clone https://github.com/TalhaHabib-hub/DSA-in-CPP.git
cd DSA-in-CPP

# Compile a file
g++ -std=c++17 path/to/file.cpp -o output

# Run it
./output          # Linux / macOS
output.exe        # Windows
```
